    Function scoreComplexity

    • scoreComplexity(word: string, freq: Map<string, number>): number

      Computes the composite reading-complexity score for a single word.

      score = w0
            + w1 · log(rarity)
            + w2 · log(syllable)
            + w3 · log(prefix)
            + w4 · log(suffix)
            + w5 · log(cluster)
            + w6 · abbreviationSignal

      using FITTED_WEIGHTS. This replaced a hand-picked equal-weight product of the same five multiplicative sub-scores (see getComplexityFeatures) — the ridge fit found how much each factor should actually count instead of assuming an exponent of 1 for all of them, and added abbreviationSignal as a sixth feature to fix single-letter tokens (see the removed-guard note below).

      Each of the five logged factors is independent:

      • wordRarity — how uncommon the word is in general English
      • syllableScore — proxy for decoding difficulty
      • morphScore — Latinate/formal suffixes signal academic register
      • prefixScore — Latinate/Greek prefixes signal technical register
      • clusterScore — rare consonant clusters signal phonological opacity

      Parameters

      • word: string

        Word to score, any casing — original casing matters for abbreviationSignal; lower-cased internally for the other five features.

      • freq: Map<string, number>

        English frequency rank map from englishFreq.json.

      Returns number

      Composite score. Compare against COMPLEXITY_THRESHOLDS (pending recalibration — see that constant's doc comment).
