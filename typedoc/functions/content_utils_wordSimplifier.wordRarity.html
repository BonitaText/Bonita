    Function wordRarity

    • wordRarity(word: string, freq: Map<string, number>): number

      Returns a rarity multiplier for word based on its English frequency rank.

      This is the single source of truth for rarity in the codebase. phraseExtractor.ts previously had its own separate rarityBonus with different rank bands — that duplicate has been removed, and keyword scoring now goes through scoreComplexity (which calls this function) via difficultyOfTerm, so the two modules can't drift onto different rarity curves again.

      Rank range Multiplier
      ≤ 1 000 1.0
      1 001–5 000 1.2
      5 001–10 000 1.3
      10 001–20 000 1.4
      > 20 000 1.6
      Not in map 1.8

      Parameters

      • word: string

        Lower-case word to look up.

      • freq: Map<string, number>

        English frequency rank map (word → rank) from englishFreq.json, loaded by the caller via getFreqMap().

      Returns number

      Rarity multiplier in [1.0, 1.8].
